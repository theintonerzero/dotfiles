# macOS Status Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `dot install` on macOS leaves a sketchybar bar of pills in place of Apple's menu bar, with Pro Black as the wallpaper.

**Architecture:** A tap-and-trust step feeds the existing formula list; a macOS-only stow package holds `sketchybarrc`, a colours file and one small shell plugin an item; `macos/bar.sh` runs the bar as a Homebrew service, hides Apple's bar through `defaults.txt`, and sets the wallpaper.

**Tech Stack:** bash, sketchybar 2.24.1, Homebrew services, `defaults`, `osascript`.

**Spec:** `docs/superpowers/specs/2026-11-14-macos-bar-design.md`

## Global Constraints

- Nothing on the bar is clickable; nothing mirrors a menu-bar icon; the bar's background is `0x00000000`.
- Only `felixkratz/formulae/sketchybar` is trusted, never the tap.
- Colours: surface `#282727`, text `#c5c9c5`, accent `#7a8382`, on-accent `#0d0c0c`, dim `#8c8882`, ok `#87a987`, err `#c4746e`. Font `JetBrainsMono Nerd Font`, 13 points; bar height 32, pill height 22.
- Fedora and Ubuntu behave exactly as they do now.
- Repo conventions: list files with `#` comments read by `list`; `say`/`warn`/`todo`; plain lowercase comments; a failing test before each change; shellcheck-clean (`~/.local/share/nvim/mason/bin/shellcheck -x`, from each file's folder); conventional commits ending with the attribution line.

## Review Focus

1. **sketchybar not installed** (the formula failed, or the tap is unreachable): the bar step says so in a todo and install carries on; Apple's menu bar is not hidden with nothing to replace it.
2. **A Mac with no battery, or no Spotify:** the battery and now-playing items draw nothing, and no script errors.
3. **Text with quotes, `$` or backticks in a track or app name:** shown as it is; never run by a shell.
4. **Pro Black's image missing,** as on a fresh macOS: plain black is set and a todo says how to get Pro Black.
5. **`dot install` run twice:** no second `brew trust`, service start, wallpaper set or `defaults write`.

### Task 2: The bar's config and its plugins

**Files:** Create `macos/home/sketchybar/.config/sketchybar/{sketchybarrc,colors.sh}` and `plugins/{space,front_app,clock,battery,volume,wifi,spotify}.sh`. Test: `tests/test_macos_bar.sh`.

**Interfaces:** each plugin is run by sketchybar with `NAME`, `SENDER` and `INFO` in its environment, and answers with one `sketchybar --set "$NAME" …` call. `colors.sh` exports `SURFACE TEXT ACCENT ON_ACCENT DIM OK ERR` as `0xffRRGGBB`.

- [ ] **Step 1: Failing tests,** each running the plugin with a `sketchybar` stub that records its arguments:
  - `battery.sh`: `pmset` saying `78%; discharging` → label `78%`, surface pill; `12%; discharging` → err pill; `20%` discharging → err; `64%; charging` → ok text; `AC attached; not charging` at 100 → plain; no battery in `pmset`'s answer → `drawing=off`.
  - `volume.sh`: muted → `drawing=on`, label `muted`, err pill; not muted → `drawing=off`.
  - `wifi.sh`: no network on the Wi-Fi interface → `drawing=on`, label `no Wi-Fi`; with one → `drawing=off`.
  - `spotify.sh`: `INFO` with `Player State` `Playing`, `Artist` and `Name` → `drawing=on`, label `Artist · Name`; `Paused` or `Stopped` → `drawing=off`; a name containing `"`, `$(touch $T/pwned)` and a backtick is shown verbatim and `$T/pwned` does not exist; a label longer than 40 characters is cut with `…`.
  - `space.sh`: `SELECTED=true` → accent pill, bold; `false` with windows → surface pill; `false` with none → no pill, dim text.
  - `front_app.sh`: `INFO=Ghostty` → label `Ghostty`; `clock.sh` sets a `HH:MM` label on `clock` and a `Sat 14 Nov`-shaped one on `date`.
  - `sketchybarrc`: sets the bar's `color=0x00000000`, `height=32`; has no `click_script` and no `alias`; every plugin it names exists and is executable; `(load macos && link_home)` links `~/.config/sketchybar/sketchybarrc`, `(load fedora && link_home)` doesn't.

### Task 3: The bar running, Apple's hidden, the wallpaper, and uninstall

**Files:** Create `macos/bar.sh`. Modify `macos/steps.sh`, `macos/defaults.txt`, `tests/test_steps.sh`, `tests/test_macos_bar.sh`.

**Interfaces:** `bar_install` (after `desktop_install` in `os_install`): with no `sketchybar` command, a `todo` and nothing else; else starts the Homebrew service unless launchd has it, reloads the bar when it is running, hides Apple's menu bar, and calls `wallpaper_apply`. `bar_update` (in `os_update`): reloads a running bar, so a pulled config shows. `bar_uninstall` (in `os_uninstall`): stops the service and unhides Apple's bar. `wallpaper_apply`: sets `WALLPAPER` (default `~/Library/Application Support/com.apple.mobileAssetDesktop/Pro Black.heic`) on every desktop when the file is there and isn't the picture already; otherwise `/System/Library/Desktop Pictures/Solid Colors/Black.png` and a `todo`.
